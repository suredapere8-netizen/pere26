# Guerra de Comunidades

Juego de estrategia y conquista en el navegador (HTML + Three.js). Elige una región de España, organiza tu ejército y conquista España, Europa y el mundo.

## Publicar en Render
1. En Render: **New → Static Site** (o **Blueprint**, que lee `render.yaml`).
2. Conecta este repositorio de GitHub.
3. Publish directory: `.` · Build command: vacío.

Nota: la «Batalla con amigos (en línea)» solo funciona dentro de claude.ai; en Render el resto del juego funciona igual.
